About

Simple by design.

Good portfolio websites do not need a complicated technology stack. The goal here is to establish a clear visual hierarchy, make the content easy to scan, and use JavaScript only where it adds value.

The page is intentionally static: there is no database, framework, build system or server-side code. That makes it inexpensive to host and easy to understand while learning.

HTML Semantic page structure and accessible content.
CSS Responsive layouts, typography and visual design.
JavaScript Small interactions without unnecessary complexity.
Git Version control for tracking changes and experiments.
Linux Comfort with command-line tools and self-hosting.
Problem solving Breaking larger technical problems into manageable steps.
